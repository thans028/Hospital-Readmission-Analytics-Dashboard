# Hospital-Readmission-Analytics-Dashboard
Developed a interactive Power BI dashboard analyzing 100,000+ hospital records to identify patterns in 30-day readmissions, patient age, length of stay, diagnoses, and previous visits. Used healthcare data analysis and visualization to communicate findings.

## Tools
- Power BI
- DAX
- Data Visualization
- Healthcare Analytics

## Key Performance Indicators
- Total Encounters
- Total Patients
- 30-Day Readmission Rate
- Average Length of Stay

## Analysis
The dashboard explores readmission patterns across patient age, length of stay, diagnosis categories, and previous inpatient visits.
